# Textos Sagrados — versión web de prueba

Análisis léxico comparado de la Biblia (King James), el Tanaj (JPS 1917), el
Corán (Pickthall 1930) y el Bhagavad Gita (Arnold 1885), todas en dominio
público. Compara frecuencias de palabras y campos semánticos entre las cuatro
tradiciones.

Esta es una versión de prueba para recoger sugerencias antes de publicar la
aplicación de escritorio. La base de datos se construye automáticamente al
desplegar. La búsqueda semántica está desactivada en esta versión ligera.

Desarrollada por Guillermo Aníbal Higuera Gómez. Código bajo licencia MIT; los
textos conservan su estatus de dominio público.
